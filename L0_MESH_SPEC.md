# L0 on a marker mesh: specification

Status: proposal, not yet built. This document is written to be argued with before any code exists. It specifies a replacement for the L0 core in `src/sim.js`.

How claims are marked:

- **[derived]**: follows from geometry, conservation or a stated equation.
- **[measured]**: an Earth range from the literature, with the source named.
- **[calibrated]**: a value chosen to make the model's output match an Earth statistic, not derived.
- **[rule]**: a modelling rule standing in for physics we do not resolve.
- **[conjecture]**: expected behaviour, to be tested.

Units are km, Myr, km² and km³ throughout, with forces in N/m (force per length of boundary) or N/m² (force per area). Useful identities: 1 cm/yr = 10 km/Myr, and 1 mm/yr = 1 km/Myr.

---

## 1. Why

The current core stores each plate as a full lattice in its own frame and resamples every plate onto a fixed lattice every step. That design has cost us in four ways:

1. **Resampling artefacts.** Rotating one lattice against another produces duplicate samples and pinholes. Three patches deal with them (README §3.3, `syncUnsampled`), and about 90% of displayed rock flicker comes from resampling (README §3.13).
2. **Plates are stored primitives with an arbitrary lineage.** Splits come from a timer and a random cutting plane; welds come from a counter threshold (ONTOLOGY.md, findings 3 and 6).
3. **Plate motion has no cause.** Angular velocities are a random walk.
4. **Exogenous inputs have no process.** Hotspots are fixed and immortal.

The replacement keeps what works: rock columns, fault records, isostasy, ocean age from birth time, conservation of continental crust, and deterministic replay.

## 2. Design principles

1. **Material is the source of truth.** Markers carry matter and history. Fields are views computed from markers. (ONTOLOGY.md, rule 1.)
2. **Plates are a pattern.** A plate is a connected component of markers bounded by boundary edges. Its identity comes from tracking components from step to step, and its lineage is recorded as a graph.
3. **The mesh is disposable.** The triangulation is used only to compute. It can be rebuilt at any time without losing information, because no history lives on it.
4. **Every exogenous input has a process.** Mantle flow and plumes are generated by stated stochastic processes, each with a magnitude and a correlation time taken from Earth.
5. **Every quantity that should be conserved has a ledger**, and is tested every step.
6. **Determinism.** A run is a pure function of (seed, options, number of steps). A snapshot restores a run exactly.

## 3. State

### 3.1 Marker

One marker is one parcel of lithosphere. The target spacing is h₀ ≈ 100 km, matching today's n = 96 lattice, which gives about 50,000 markers. Arrays are structure-of-arrays, indexed by slot; a slot is reused after its marker is deleted, but a marker's **id** is never reused.

| Field | Type | Meaning |
|---|---|---|
| `id` | uint32 | Permanent identity. Never reused. |
| `x, y, z` | float64 | Position on the unit sphere, world (mantle) frame. |
| `plate` | int16 | Plate component this step. Derived (§4.6), stored for speed. |
| `A` | float64 | Carried area, km². Changes only through strain (zero for rigid plates), ridge accretion, consumption, splitting and merging (§4.3–4.5). |
| `V` | float64 | Crustal volume, km³. Thickness is T = V / A. |
| `K` | uint8 | 1 if continental. |
| `B` | float32 | Birth time of the crust, Myr. For ocean it fixes depth through √age. |
| `S` | float32 | Sediment on oceanic crust, km. |
| `col` | int32 | Rock column in the shared column pool: units of rock type, birth time, thickness and plate, as now. |
| `flt` | int32 | Fault record: two episodes, as now (README §3.10). Strike stored in the plate's body frame. |
| `D` | float32 | Damage, 0 to 1 (§6.3). |
| `parent` | uint32 | Id of the marker this one was split from, if any. |

**Invariant [derived]:** V = A × T. Every process changes V, or A, or both, through a ledgered operation (§7). T is never set directly.

### 3.2 Mesh

- **The Delaunay triangulation of the marker positions.** On a sphere, this is exactly the convex hull of the points in 3D [derived], which makes it simple and robust to build.
- **Maintenance:** after each step's motion, local Lawson edge flips restore the Delaunay property; markers move less than one spacing per step, so few flips are needed. A full rebuild (incremental 3D convex hull, expected O(N log N)) runs at start, after restore, and as a fallback if a flip pass fails a validity check.
- **Derived per step:**
  - Voronoi area A_vor of each marker, from the circumcentres of its incident triangles.
  - Neighbour lists, and cotangent weights for the diffusion operators.
  - Edge labels: interior (both ends on one plate) or boundary (ends on different plates).

### 3.3 Mismatch: where gaps and overlaps are

The one new quantity that does all the boundary bookkeeping:

> m = A_vor − A

- **m > 0**: the marker's carried area is less than the space it occupies. The surface has opened: a **gap**.
- **m < 0**: the marker carries more area than it has room for. Plates **overlap**.

Rigid plates moving apart make m positive on both flanks of the boundary, and moving together make it negative. Inside a rigid plate, m stays near zero. **[derived]:** the sum of A_vor is exactly 4πR², so the sum of m equals 4πR² minus the sum of A. Closing the area budget therefore means driving m back toward zero, which is what ridge accretion (§4.3) and consumption (§4.4) do.

### 3.4 Plates and lineage

A plate record is derived each step from the components:

| Field | Meaning |
|---|---|
| `id` | Lineage identity (§4.6). |
| `ω` | Angular velocity, rad/Myr, from the torque balance (§5). |
| `Q` | Accumulated orientation, 3×3, integrated from ω. Kept so fault strikes and L1's reference frames work as now. |
| `markers` | Member list. |
| `area`, `contArea`, centroid | Statistics. |

**The lineage graph** has one node per (plate id, time interval) and edges labelled `continue`, `split` or `weld`. It is append-only and part of the snapshot. It replaces today's `parent` and `mergedInto` fields.

### 3.5 Mantle state

| Item | Content |
|---|---|
| Flow modes | Real spherical-harmonic coefficients of a poloidal potential Φ and a toroidal potential Ψ, degrees 1–4. The basal mantle velocity is v_m = ∇Φ + r̂ × ∇Ψ on the sphere. |
| Plumes | List of {position, birth time, phase, flux, drift state, death time} (§6.2). |
| Slab record | As now: consumed oceanic area, weighted by age, in 10 Myr bins on a fixed mantle grid. |

### 3.6 Rendering grid (temporary compatibility)

The fixed cube-sphere grid stays as a view: each step, markers are interpolated onto it (nearest marker for categorical data like rock and plate; barycentric on the triangle for continuous data like elevation). It produces today's arrays (`owner`, `wK`, `wT`, `elev`, `wCol`, `wR`, `wRA`), so the UI, the handoff export and L1 keep working during the migration (§9). It is a view and is never written back.

## 4. One step

The time step dt is limited so the fastest marker moves at most 0.5 h₀ per step [rule], which is about 0.6 Myr at 8 cm/yr. The order matters and is fixed.

### 4.1 Forces and velocities

1. Update the mantle state by dt (§6).
2. Solve the torque balance (§5) for each plate's ω.
3. Every few steps (configurable, default 5), run the stress solve (§6.3) and update damage.

### 4.2 Move

1. Rotate each marker about its plate's pole by |ω|·dt (Rodrigues' formula, as now); integrate each plate's Q.
2. Restore the Delaunay property by edge flips (§3.2). Recompute A_vor and m.

### 4.3 Ridge accretion (gaps) [rule]

1. Find boundary faces whose vertices have a summed positive mismatch above A_min = 0.5 h₀².
2. Insert a new oceanic marker at the circumcentre of the face with the largest mismatch, repeating until no face qualifies.
   - **New material:** K = 0, B = now, T = 7 km, S = 0, a fresh column (ocean basalt), damage 0.
   - **Plate:** the plate of its nearest existing vertex; ties go to the lower plate id. Over many insertions this gives symmetric spreading [conjecture, to test].
   - **Area:** its A is set to its Voronoi area after insertion. This reduces its neighbours' A_vor, and so their positive mismatch.
3. Ledger: oceanic area and volume created.

This is today's gap rule c (README §3.3), applied where the geometry says the surface opened instead of where sampling failed.

### 4.4 Consumption (overlaps) [rule]

At each convergent boundary, find the clusters of negative mismatch. The overlap area to remove is the sum of −m in the cluster. The **loser** is chosen by today's `resolve()` rule: continental beats oceanic, then thicker beats thinner, then younger beats older.

**Oceanic loser: subduction.**

- Remove carried area from the loser's boundary markers, nearest the boundary first, until the overlap is closed. Their volume is removed in proportion. A marker whose A falls below 0.05 h₀² is deleted.
- Write the consumed area, weighted by age, into the slab record (as now).
- Add an arc to the winner, 1–3 spacings inboard, as now. The arc's volume is new crust from the mantle, not the consumed crust. The amount is [calibrated] so global arc production is about 3 km³/yr [measured: Scholl & von Huene 2009, on the order of 2–3 km³/yr of new continental crust].
- Mark the boundary edges as a trench (used for slab pull, §5.2).

**Continental loser: collision.**

- Remove the overlap area from the loser's boundary markers as above, but **move all of their volume** to the winner's markers in the collision zone, weighted as now (inboard for head-on convergence, at the boundary for glancing). Push an OROGEN unit onto each receiving column.
- **[derived]:** continental volume is conserved exactly. The winner's markers keep their A and gain V, so they thicken.
- A loser marker whose A falls below 0.05 h₀² is deleted. Its column is appended to the nearest winner marker's column, so its history survives as material.

Ledger: every operation records area and volume, by kind (§7).

### 4.5 Refinement and coarsening

- **Split** a marker into two along its principal stretch direction when its A_vor > 2 h₀², or when local strain rate or thickness gradient exceeds a threshold (crumple zones). The children share V and A equally, copy the column and fault record, and record `parent`. New ids.
- **Merge** two neighbouring markers on the same plate when:
  - both have A < 0.5 h₀²;
  - their thicknesses differ by less than 2 km;
  - their columns satisfy the formation-linking rule (same rock type and origin plate per unit, ages within max(40 Myr, 10%); README §3.11).

  The merged marker sums V and A, keeps the older id, and its column is the thickness-weighted union of the two. The merge is recorded in the parcel-lineage log (§8) so L1 can follow parcel identity back.

### 4.6 Plate components and lineage

1. **Boundary edges** are edges that are cracks or ridges (§6.3), or that join markers of plates with relative velocity above 0.2 cm/yr. All other edges are interior.
2. **Components:** union-find over markers through interior edges.
3. **Matching to last step:** each component takes the id of the previous plate it shares the most markers with, provided it holds at least half of that plate's markers. Other components get new ids, with a `split` edge from the plate they came from. Two previous plates absorbed into one component give a `weld` edge; the larger keeps its id. **[rule]:** this is the naming convention, made explicit.
4. **Welding [rule]:** a convergent boundary between two continental markers whose relative velocity stays below 0.5 cm/yr for τ_weld = 15 Myr heals: its edges become interior, and the components merge at the next step. This replaces the collision counter. It is falsifiable: the time from first continental contact to welding should be tens of Myr [measured: India–Asia, still converging about 50 Myr after contact, so τ_weld may need to be a strain criterion instead; open question].

### 4.7 Surface processes

The same rules as now, ported from the lattice to the mesh:

- **Diffusion** of continental thickness, using the cotangent Laplacian.
- **Erosion** in proportion to elevation, with sediment routed to lower neighbours in proportion to the drop.
- **Ocean edifice decay**, conversions to continent (shelf, arc), collapse.
- **Hotspots** become plumes (§6.2).

Elevation is computed from the column by isostasy, as now (`elevOf`). In Stage 1 every rule keeps its current constants, so the new core can be compared with the old one directly.

### 4.8 Records and events

- The fault record is updated per marker from the relative velocity across adjacent boundary edges, as now (`recordFaults`).
- **Two event kinds:**
  - **Causal:** rift, weld, plate lost, plume birth, plume head arrival, plume death.
  - **Observed:** island emerges, collision begins.

  These are separated in the log (ONTOLOGY.md, finding 5).
- The per-step tectonic thickening record for L1 (`tecRec`) is splatted to the rendering grid.

## 5. Plate driving forces: torque balance

### 5.1 The equation

Each plate p is rigid in this tier, so its motion is ω_p (3 unknowns). For each plate, the torques sum to zero:

> τ_drive,p + τ_mantle,p − C_b M_p ω_p − Σ_q B_pq (ω_p − ω_q) = 0

- M_p = ∫_p k(r) (I − r rᵀ) R² dA is the plate's drag tensor. k(r) is 1 under ocean and k_keel under thick continent.
- τ_mantle,p = C_b ∫_p k(r) r × v_m dA R is the torque from the mantle flow underneath.
- B_pq = c_pq ∫_{boundary pq} (I − r rᵀ) R² dl couples neighbouring plates along their shared boundary.

**[derived]:** the system is linear in the ω, with a symmetric positive-definite block matrix of size 3P × 3P. With P ≤ 30 plates it is at most 90 × 90, solved directly. Net rotation relative to the mantle is no longer removed by fiat: it falls out of the balance. A switch keeps the old removal available for comparison.

### 5.2 Forces

| Force | Form | Magnitude |
|---|---|---|
| **Slab pull** | At each trench edge on the subducting plate, perpendicular to the trench: F_sp = f_sp · Δρ · g · h(age) · L_slab | Δρ ≈ 50–80 kg/m³; h(age) ≈ 2.32√(κ·age) [derived: half-space cooling]; L_slab grows with accumulated convergence at that trench, capped at about 700 km (to 660 km depth). The transmitted fraction f_sp ≈ 0.1–0.5 [calibrated]. Full pull is of order 10¹³ N/m [measured: Turcotte & Schubert, *Geodynamics*] |
| **Ridge push and spreading** | A body force from gravitational potential energy (GPE): f = −∇_s GPE, integrated over the plate. For ocean, GPE grows with age, so the force points away from ridges; for continent, it grows with thickness | Integrated ridge push about 2–3 × 10¹² N/m at 100 Myr [measured: Turcotte & Schubert]. The same term covers continental spreading, so it is one force, not two |
| **Basal drag** | −C_b k(r) (v_plate − v_m) per area | C_b = η_asthenosphere / h_asthenosphere. With η ≈ 10¹⁹–10²⁰ Pa s and h ≈ 100–200 km, C_b ≈ 10¹⁴–10¹⁵ Pa s/m [measured range]. Keel factor k_keel ≈ 3–10 under cratons [conjecture; literature disagrees] |
| **Boundary coupling** | c_pq per unit boundary length. Small for ridges and transforms, large for continental collision | [calibrated], chosen so that continental collision slows convergence by a factor of 2–4 within 10–20 Myr [measured: India slowed from about 15 to about 4 cm/yr around 50–40 Ma] |

**Sanity check [derived]:** one plate with 5,000 km of trench at F_sp = 10¹³ N/m has a driving force of about 5 × 10¹⁹ N. Balanced by drag on 5 × 10¹³ m² of plate at C_b = 10¹⁴ Pa s/m, its speed is about 10⁻⁸ m/s ≈ 30 cm/yr. That is six times too fast, so either f_sp is near its low end or C_b near its high end. The pair (f_sp, C_b) is therefore **[calibrated]** jointly against Earth's root-mean-square (RMS) plate speed of about 4–5 cm/yr, and only their ratio is constrained. This is stated, not hidden.

## 6. Exogenous processes

### 6.1 Mantle flow [rule with measured parameters]

- **Form:** v_m = ∇Φ + r̂ × ∇Ψ, with Φ and Ψ expanded in real spherical harmonics of degrees 1–4.
- **Spectrum:** most power at degree 2 [measured: Earth's lower mantle is dominated by two antipodal large low-shear-velocity provinces (LLSVPs), under Africa and the Pacific].
- **Time evolution:** each coefficient follows an Ornstein–Uhlenbeck process, dc = −c dt / τ_m + σ √(2/τ_m) dW. This is the "random walk with justified magnitude and coherence":
  - correlation time τ_m ≈ 50–200 Myr [measured order: mantle overturn time];
  - σ set so the RMS of v_m is 1–3 cm/yr [calibrated].
- **Coupling:** v_m acts on plates only through basal drag (§5.2). Its divergence (upwelling) adds a dynamic-topography term to elevation, alongside the slab record.
- **Optional mild two-way coupling:** the slab record adds a downwelling to Φ. Off by default.

### 6.2 Plumes [rule with measured parameters]

| Phase | Rule | Earth range |
|---|---|---|
| Birth | Poisson process, rate λ_p. Position drawn with probability rising toward the edges of the degree-2 upwellings | Rate about 1 per 5–10 Myr, keeping 10–20 deep plumes alive [measured order]. Plumes rising from LLSVP margins: Burke & Torsvik (2004), "plume generation zones" |
| Head arrival | After a rise time of about 10 Myr, a large igneous province: volume drawn log-uniform over 10⁶–10⁷ km³, emplaced over 1 Myr in a disc about 1,000–2,000 km across; a swell of about 1 km; damage added to the plate above | Deccan, Siberian Traps, Paraná–Etendeka [measured] |
| Tail | Flux 0.01–0.2 km³/yr. Log-flux pulses as an OU process with τ ≈ 10 Myr | Hawaii's flux has varied severalfold along the chain [measured] |
| Drift | The plume moves with the mantle flow at a fraction 0.3–0.5 of v_m | 0–2 cm/yr, briefly about 4 cm/yr [measured: Tarduno 2003] |
| Death | Lifetime lognormal, median about 80 Myr | 50–130+ Myr [measured: Tristan about 130, Hawaii ≥ 80, Iceland about 60] |

Plume heads add damage, so they can trigger rifts: continental breakup above large igneous provinces (Paraná–Etendeka and the South Atlantic, Deccan and the Seychelles) becomes something the model can produce rather than something we place [conjecture, to test].

### 6.3 Stress, damage and cracking (Stage 4)

**Stress solve.**
- After the torque balance, each plate's loads (body forces, basal traction at the solved ω, slab pull, coupling tractions) are in equilibrium [derived: that is what the torque balance enforces]. So a static elastic membrane solve on the plate is well posed.
- Method: linear finite elements on the plate's triangles, conjugate-gradient solve, rigid rotations removed.
- Stiffness is proportional to strength × (1 − D), so damaged zones carry less stress.
- Output: the depth-integrated stress tensor per marker, in N/m.

**Strength.** Depth-integrated lithospheric strength S, in N/m [measured order: 10¹²–10¹³ N/m]:
- ocean: S grows with √age;
- continent: S grows with thermal age, highest in cratons.

The effective strength is S(1 − D).

**Damage.**

> dD/dt = (1/τ_d) · max(0, σ_II / (S(1 − D)) − 1) · (1 − D) + plume term − D / τ_heal

- σ_II is the second invariant of the deviatoric stress.
- τ_heal is a few hundred Myr [conjecture]. Slow healing is what lets old sutures stay weak and be reused: Wilson-cycle inheritance.

**Cracking [rule].** When a marker's tensile normal stress exceeds its effective strength:
1. Grow a path in both directions along mesh edges, by Dijkstra's shortest-path algorithm, with edge cost = length × max(ε, S(1 − D) − σ_nn) × e^ξ.
   - σ_nn is the tension across the edge.
   - ξ is deterministic noise (a hash of the edge's marker ids and the seed), standard deviation about 0.3.
2. Stop when the path reaches an existing plate boundary at both ends.
3. Accept the path if its mean overstress is positive. Its edges become boundary edges with D = 1. The component splits at the next step (§4.6), and ridge accretion (§4.3) opens it if the torque balance moves the halves apart.

Compression does not split plates. It raises damage and, through §4.4, thickens crust.

## 7. Invariants and ledgers (tested every step)

| # | Invariant | Tolerance |
|---|---|---|
| I1 | Area: \|Σ A − 4πR²\| / 4πR² | < 10⁻³; the largest \|m\| / h₀² bounded |
| I2 | Continental volume ledger: the change in Σ V over continental markers equals arcs + accretion + plumes on continent + conversions − erosion to ocean − conversions to ocean | 10⁻⁹ relative |
| I3 | Oceanic area ledger: created at ridges − consumed at trenches − converted = change in oceanic area | 10⁻⁹ relative |
| I4 | Mesh validity: every triangle positively oriented; Delaunay after flips; every marker belongs to exactly one plate | Exact |
| I5 | Identity: marker ids unique and never reused; the plate and parcel lineage graphs are acyclic | Exact |
| I6 | Determinism: two runs from one seed give an identical state hash at step 500; restoring a snapshot and replaying gives an identical hash | Exact |

## 9. Staged plan

Each stage ends with checks that can fail. The old core stays selectable in the page until Stage 1's checks pass, so the two can be compared on one seed.

| Stage | Builds | Exit checks |
|---|---|---|
| **1. Markers and mesh, today's rules** | Markers, convex hull and flips, Voronoi area and mismatch, ridge accretion, consumption, refinement, components and lineage, rendering grid. Velocities still a random walk, splits still by timer, hotspots as now | I1–I6 pass. Over 800 Myr on three seeds, these statistics fall within today's ranges (README §3.13): land fraction, continental fraction, peak elevation, plate count, rift and suture counts. Rock flicker from resampling drops to about 0. Cost within 2× of today's per step |
| **2. Torque balance** | §5. Random walk removed | RMS speed 3–6 cm/yr [calibrated]. Plates with a larger share of trench boundary move faster, rank correlation > 0.5 [measured: Forsyth & Uyeda 1975]. Continental collision slows convergence 2–4× within 20 Myr. Net rotation < 0.4°/Myr [measured: estimates for Earth relative to hotspots range about 0.1–0.4°/Myr] |
| **3. Mantle and plumes** | §6.1 and §6.2. Fixed hotspots removed | Plume lifetimes, drift and large igneous province frequency within the table's ranges. Hotspot tracks bend and age along their length |
| **4. Stress, damage, cracking** | §6.3. Split timer removed | Rift rate within 15–60 per Gyr without being set. Rifts start on old sutures more often than a random path through the same plate would [conjecture: the Wilson-cycle test]. Fraction of rifts within 1,000 km of a plume head reported |
| **5. Crust budget without the thermostat** | Replace the 40% thermostat with process rates: arc production against sediment subduction and subduction erosion | Continental fraction stays in 30–45% for 1 Gyr. Earth's continental volume has been roughly steady, with addition and loss each about 3 km³/yr [measured: Scholl & von Huene 2009]. If this fails, the thermostat stays and is labelled a fudge, as now |
| **6. L1 on markers** | L1 seeds from L0's markers and reads the lineage graph; the compatibility rendering grid is used only for display | test_l1 passes unchanged in what it checks |

Statistics reported at every stage, compared with Earth:

| Statistic | Earth |
|---|---|
| Plate count and size distribution | About 50+ plates when microplates are counted; a power-law tail of small plates [measured: Bird 2003] |
| Mean ocean-floor age | About 60 Myr; the oldest in place about 180 Myr |
| Ocean area against age | Declines roughly linearly [measured: Parsons 1982] |

For comparison, today's core gives a mean ocean-floor age wandering between 70 and 220 Myr (README §3.13): it recycles seafloor too slowly.

## 10. Cost estimate [conjecture until measured]

Per step at about 50,000 markers, in JavaScript on one core:

| Part | Estimate |
|---|---|
| Rotate markers | < 1 ms |
| Edge flips and Voronoi areas | 5–15 ms |
| Accretion, consumption, refinement | 2–5 ms |
| Components and lineage (union-find) | 2–3 ms |
| Torque balance (90 × 90 solve plus integrals) | 1–3 ms |
| Surface processes | 5–10 ms |
| Rendering grid | 3–6 ms |
| Stress solve, every 5 steps | 50–150 ms, amortized 10–30 ms |

The total is plausibly 30–70 ms per step, against today's 22–25 ms. The stress solve and the rendering grid can move to Web Workers if needed, as L2's burn-in did.

## 11. Open questions

1. **Rigid plates, or a full sheet?** This spec keeps rigid plates with rules at boundaries (Stages 1–5). The alternative is L1's thin viscous sheet on the whole sphere, with damage-dependent viscosity, so plates emerge as nearly rigid regions (as in Bercovici's damage-rheology convection models). That is more faithful and more expensive. Recommendation: rigid first, sheet as a later Stage 7 if the rules prove limiting.
2. **Welding criterion.** India is still converging about 50 Myr after contact, so a criterion based on velocity may never fire there. Possibly it should be accumulated strain or thickening instead.
3. **Subduction initiation.** New trenches currently appear only where plates already converge. On Earth, passive margins sometimes start subducting. One route: damage and GPE contrast at old ocean–continent margins. Not yet specified.
4. **Continental subduction and exhumation.** Ignored; all consumed continental crust stays at the surface.
5. **Resolution.** h₀ = 100 km fixed, with adaptive refinement in crumple zones up to 4× finer. Is a coarser default worth it for speed?
6. **Initial conditions.** Same as today (noise continents or a supercontinent). A spun-up start (run 500 Myr before t = 0) may be needed so slab lengths and damage are not all zero.
